# macOS Modern

A macOS-inspired Discord theme with translucent glass surfaces, soft color reflections, and compact traffic-light window controls. The wallpaper is embedded in the theme file, so it does not depend on an external image host.

![macOS Modern theme preview](./macOS-Modern-preview.png)

## Features

- Frosted-glass styling for Discord panels, menus, and the message composer
- Light and dark color palettes with readable text contrast
- macOS-style close, minimize, and maximize controls
- Embedded wallpaper with no external image request
- Reduced-motion support

## Installation

### BetterDiscord

1. Download `macOS-Modern.theme.css` from this repository.
2. In Discord, open **User Settings > Themes**.
3. Select **Open Themes Folder**, place the downloaded file there, and enable the theme.

### Vencord

1. Download `macOS-Modern.theme.css` from this repository.
2. In Discord, open **User Settings > Vencord > Themes**.
3. Open the themes folder, place the downloaded file there, and enable it.

## Customization

The wallpaper is stored in the `--wallpaper` variable near the top of `macOS-Modern.theme.css` as a self-contained WebP data URI. Replace that value with another image URL or data URI to use a different wallpaper.

## Compatibility

Designed for current BetterDiscord and Vencord builds. Discord updates may change internal class names and require theme adjustments.
